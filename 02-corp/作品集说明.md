# 作品集 02 · 企业官网（恒远机械）

> 演示项目。公司、地址、电话、参数表均为虚构，页脚与表格下方已标注。
> 真多页站点：**5 个页面 + 1 个公共样式文件**。

## 页面结构

| 文件 | 页面 | 主要模块 |
|---|---|---|
| `index.html` | 首页 | 首屏 + 三块业务 + 四步流程 + 案例预览 + CTA |
| `products.html` | 产品与参数 | 产品卡 + **参数表格** + 选型四问 |
| `cases.html` | 项目案例 | 六宫格案例（行业 / 问题 / 做法） |
| `about.html` | 关于我们 | 公司介绍 + **时间轴** + 质保说明 |
| `contact.html` | 联系我们 | 询价表单 + 联系方式 + 常见问题 |
| `assets/styles.css` | 公共样式 | 所有页面共用一套变量与组件 |

## 这一站展示什么能力

| 客户能看到的 | 对应能力 |
|---|---|
| 5 页共用一套导航和页脚 | 多页面站点结构，改一处全站生效 |
| 参数表格（型号/风量/功率） | 工业、设备类企业最需要的模块 |
| 案例六宫格 + 行业标签 | 让客户看懂"你做过什么" |
| 时间轴、质保卡片 | 关于页不是一段干巴巴的简介 |
| 询价表单 + 常见问题 | 转化路径完整 |
| 手机端一列到底 | 真响应式（390 / 768 / 1440 验过） |

## 技术说明

- **纯静态**：HTML + 一个 CSS 文件，不需要数据库
- **组件化写法**：顶部信息条 / 导航 / 卡片 / 步骤 / 表格 / 时间轴 / 页脚都是可复用类名，客户加页面直接套
- **配色全走变量**：改 `:root` 里 5 个值就能换整套色
- **无外部依赖**：系统字体 + CSS 图形，打开很快，也不会有"图片加载不出来"的窘况
- **表单**：演示版是纯前端；正式交付时接金数据 / 飞书表单，或客户自己的后端

## 换成客户的公司要改什么

| 位置 | 改动 |
|---|---|
| 全站品牌名 | 搜 `恒远机械` 替换（5 个页面 + 页脚） |
| 电话/地址 | 搜 `400-000-0000` 和 `示例地址` 替换 |
| 产品与参数表 | 换成客户真实型号与参数 |
| 案例 | 换成客户真实项目（客户名可用"某汽车零部件厂"这种写法） |
| 图块 `.figbox` / `.case .ph` | 换成实拍照片 |
| 表单 | 接客户的接收渠道 |
