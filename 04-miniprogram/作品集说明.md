# 作品集 04 · 微信小程序（山野瑜伽 · 课程预约）

> 演示项目。店名、地址、电话、课程均为虚构，页面已标注。
> 标准小程序项目结构，**可以用微信开发者工具直接导入运行**。

## 页面结构

| 页面 | 文件 | 内容 |
|---|---|---|
| 首页 | `pages/index/` | 门店定位语 + 今日课程 + 两个入口按钮 |
| 课程表 | `pages/schedule/` | 日期切换 + 课程卡片 + 剩余名额 |
| 预约 | `pages/book/` | 课程信息 + 三个输入框 + 提交（含必填校验） |

公共样式在 `app.wxss`（配色写在一个 `page{}` 变量块里，改 6 个值就能换整套色）。

## 这一项展示什么能力

| 客户能看到 | 对应能力 |
|---|---|
| 三个页面互相跳转、带参数 | 小程序路由与页面传参 |
| 日期切换、名额显示 | 列表渲染与状态切换 |
| 表单必填校验 + 提交反馈 | 表单交互 |
| 手机号一键拨打 | 小程序原生能力调用 |
| 清一色的圆角卡片、克制的配色 | 移动端视觉规范 |

## 怎么跑起来

1. 下载安装**微信开发者工具**（免费）
2. 打开 → 导入项目 → 选择这个文件夹 → AppID 选「测试号」
3. 直接就能预览三页

> 说明：我这边只验证了项目结构完整（页面注册、文件齐全、样式变量统一），
> **没有在这台机器上跑过微信开发者工具**（本机没装）。你导入后如果报错，把报错发我，我改。
