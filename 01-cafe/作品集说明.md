# 作品集 01 · 门店单页官网（慢煮咖啡）

> 演示项目。品牌、地址、电话、豆单均为虚构，页脚已标注。
> 一套文件：`index.html`（单文件，内联样式，扔到任何静态托管都能跑）

## 这一页展示什么能力

| 客户能看到的 | 对应我们会的 |
|---|---|
| 首屏不对称双栏、大字标题 | 排版与信息层级 |
| 错落的豆单卡片（三张不同高度） | 版式节奏，不是模板套娃 |
| 深绿预约区块 + 表单 | 表单与转化区设计 |
| 手机上一列到底、不横滚 | 真响应式（390 / 768 / 1440 都验过） |
| 顶部信息条（营业/位置/电话） | 门店类客户最常要的模块 |

## 技术说明（给客户看的版本）

- **纯静态**：一个 HTML 文件，不需要数据库、不需要服务器（扔 Vercel / 宝塔 / 虚拟主机都行）
- **不依赖外部资源**：字体用系统字体，图块是 CSS 画的（换成客户的实拍图即可），**打开速度极快**
- **自带 SEO 基础**：title / description 已写好
- **响应式**：320–1440 都排过版，无横向滚动

## 改成客户的店，需要改哪里

| 位置 | 改什么 |
|---|---|
| `<title>` 和 `<meta description>` | 店名 + 一句话介绍 |
| 首屏 h1 / lede / meta | 主打卖点 + 营业信息 |
| 豆单三张卡 | 换成真实产品/服务 |
| `.shot` 两个图块 | 换成实拍照片（`background-image` 或 `<img>`） |
| 预约区 | 接客户自己的表单（金数据、飞书表单，或后端接口） |
| 页脚 | 真实地址、电话、备案号 |

## 配色（可整体换）

改文件开头 `:root{}` 里的四个值就能换全套：
`--paper` 米白底 / `--ink` 主文字 / `--terra` 砖红强调 / `--moss` 墨绿区块
