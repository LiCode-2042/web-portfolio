作品管理后台

在这里改作品，保存后直接提交到 GitHub，网站一分钟左右自动更新。不用碰任何代码。 　先看看现在的网站 →

① 先设置一次令牌

令牌只存在你自己这个浏览器里（localStorage），不会进仓库、不会发给别人。换台电脑要重新粘一次。

还没有令牌？点这里看怎么建（一次性，2 分钟）
  1. 浏览器打开 github.com/settings/personal-access-tokens/new（要用你自己的 GitHub 账号登录）
  2. Token name 随便填，比如 portfolio-admin
  3. Expiration 建议选 90 天（到期再建一个）
  4. Repository access 选 Only select repositories，只勾 web-portfolio（别给全部仓库权限）
  5. Permissions → Repository permissions 找到 Contents，改成 Read and write；其它都不用动
  6. 点最下面 Generate token，把生成的字符串整段复制（离开页面就再也不显示了）
  7. 粘到上面那个框，点「保存令牌」

② 改作品

改完点最下面的「保存到线上」。上移/下移决定作品在首页的顺序。

提交信息会自动带上时间
