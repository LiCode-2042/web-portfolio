# 取色器 · Palette Picker（浏览器插件示例）

## 它做什么

点一下插件图标 → 读取当前网页用到的颜色和字体 → 列出主色 Top 8 和字体使用次数 →
点任意色块或字体名，直接复制色值 / 字体名。

**用途**：看到喜欢的网站想抄配色、想知道对方用什么字体，不用开 DevTools 一个个翻。

## 怎么装（Chrome / Edge，30 秒）

1. 打开 `chrome://extensions/`（Edge 是 `edge://extensions/`）
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择这个文件夹
4. 浏览器工具栏就能看到它了（可能要在一个拼图图标里固定一下）

## 怎么用

打开任意网页 → 点插件图标 → 点「读取当前页配色」→ 点色块复制。

> 浏览器设置页、扩展商店页这类特殊页面读不到，会提示"此页面不允许读取"，这是浏览器的限制，不是插件坏了。

## 技术说明

- **Manifest V3**（Chrome 现在要求的版本）
- 只申请三个权限：`activeTab`、`scripting`、`clipboardWrite`——**不读你的历史、不联网、不上传任何数据**
- 提取逻辑在页面里跑，只统计颜色和字体，不采集文本内容
- 代码量小，一个 `popup.html` + 一个 `popup.js`，任何客户都能自己看懂

## 换成客户要的功能

这套骨架可以改造成：

- **一键截图存图**（加 `captureVisibleTab`）
- **页面元素标注 / 取尺寸**（读取元素宽高、边距）
- **一键复制页面标题+链接+摘要**（做笔记用）
- **把当前页存到自己的收藏系统**（接一个接口）
